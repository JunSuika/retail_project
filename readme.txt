Cómo ejecutar el query:
			-Asegurarte de que tu motor sea PostgreSQL.
			-Abrir tu interfaz de preferencia.
			-Abrir el archivo .sql.
			-Ejecutar los comandos paso a paso; primero el create database/schema, luego cada 			 create table, luego cada commit.
			-Cada vez que se ejecuta un comando, darle a refresh (o a F5).
